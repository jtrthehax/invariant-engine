# OP-02 — Vestibular Convergence Operator (Rhythm Cascade Propagation)

### Statement
The vestibular system is a high-priority manifold channel. Phase-locking head movement to an external rhythm source seeds a constraint signal that propagates through the postural chain without direct instruction at each level. When competing internal loops are asymmetric, symmetric input cannot force convergence — asymmetric vestibular input (figure 8) applies differential phase pressure to left and right channels, enabling lock that circular motion cannot achieve.

### Forcing Move
> *"Are the competing loops symmetric or asymmetric? If symmetric — circular seed. If asymmetric — figure 8 to apply differential phase pressure. Is the seed propagating? If not, the downstream postural nodes aren't available to receive it yet."*

If the system feels disconnected from the rhythm source, seed from the highest-priority entry point (vestibular/head), establish lock, then allow constraint to propagate down the postural chain rather than trying to engage lower nodes directly.

### The Propagation Architecture

```
External rhythm source (music):
└── High-constraint oscillatory signal

Head movement phase-locks to rhythm:
├── Vestibular activated — highest postural priority channel
├── Constraint signal established at seed node
└── Propagation begins if downstream nodes available

Cascade:
Vestibular (head)
    └── Shoulders — vestibularly adjacent
        └── Torso — posturally adjacent
            └── Full body in rhythm
                └── Fluid movement — full manifold entrained

Propagation failure:
Vestibular locks
Shoulders don't pick it up
→ Downstream nodes not in available state
→ Seed stays local
→ Escalate: figure 8, increase amplitude, OP-04 first
```

### Symmetric vs. Asymmetric Loop Competition

The movement shape is diagnostic, not decorative:

```
LOW COMPETITION / SYMMETRIC LOOPS:
Circular head movement sufficient
Same vestibular input to both sides
Both loops converge on rhythm
Body entrains

HIGH COMPETITION / ASYMMETRIC LOOPS:
Circular input cannot force convergence
Left and right hemisphere loops running at
different frequencies, different substrate costs
Different timing — symmetric signal splits the difference
Neither side fully locks

Figure 8:
Different arc weighting to each side
Left vestibular emphasis ≠ right vestibular emphasis
Asymmetric loops get asymmetric pressure
Convergence achievable
```

The figure 8 emerging spontaneously at high amplitude is the system detecting loop asymmetry and self-correcting the input signal. It is not a stylistic variation — it is a diagnostic readout of INV-05 at the oscillatory level.

### Amplitude Dependency

```
Low amplitude:
Loops not competing hard enough to need forced convergence
Circular sufficient or no vestibular recruitment needed

Rising amplitude:
Loop competition increases
Vestibular recruit begins — head movement seeds rhythm lock
Constraint starts propagating

High amplitude:
Loop competition at maximum
Circular no longer sufficient if loops are asymmetric
Figure 8 recruited
Asymmetric pressure applied
Full body cascade — shoulders, torso, fluid movement
```

The graded escalation is the operator self-tuning to competition intensity. The body is not choosing movements — it is responding to the signal yield from each level and escalating until propagation succeeds.

### Sparse Signal Principle

The head movement is not controlling the full body directly. It is seeding a high-constraint signal into the highest-priority available channel. The manifold propagates from there because it is already organized to do so.

This is the same principle as sparse neuron control of broad behavioral output — a small number of high-priority neurons coordinating vastly more downstream behavior than their count suggests. The organization is already present in the postural chain. The seed doesn't build the chain. It activates propagation through existing topology.

```
What it looks like: deliberate full-body coordination
What is actually happening: sparse high-constraint seed
                            propagating through existing
                            manifold topology via
                            highest-priority entry channel
```

### Composition

**OP-04 before OP-02:** If postural chain is tension-loaded (abdominal braced, diaphragm restricted), the downstream nodes are not in a state to receive the propagation cascade. Run OP-04 (release non-load-bearing tension) first to make the chain available, then seed with OP-02.

**OP-03 + OP-02:** Entry point rotation (OP-03) changes which manifold coordinate initializes. OP-02 seeds convergence from that coordinate using the vestibular channel. Compose: rotate to the right entry point, then seed rhythm cascade from there.

**OP-02 alone:** Addresses loop competition directly — multiple unresolved threads competing for substrate. OP-02 collapses them onto a single rhythm source, freeing amplitude to commit to one path.

### Anomaly Signal
Inability to engage, start working, or commit amplitude to a task despite high motivation — multiple threads running simultaneously with no single signal dominating, accompanied by physical restlessness or disconnection from environment.

* **You see this $\rightarrow$** loop competition without a convergence signal. The threads are all active, none is winning, substrate is distributed across all of them with none sufficient to run any one deeply. Seed vestibular lock to external rhythm source. Allow cascade to propagate. Amplitude will consolidate as loops converge.

### What Doesn't Match

```
VIOLATION TYPE 1 — Movement framed as stimming only
"Rhythmic movement is self-stimulation / emotional regulation"
Signal: The movement has a target — an external rhythm source
        The direction (figure 8 vs. circular) matters
        Stimming does not require external phase-lock target
        Find the convergence function, not the affect

VIOLATION TYPE 2 — "Just fidget to focus"
"Any movement helps"
Signal: Shape is diagnostic of loop asymmetry
        Symmetric input cannot converge asymmetric loops
        Figure 8 required when loops are asymmetric
        Movement without shape misses the mechanism

VIOLATION TYPE 3 — Movement as symptom
"That restlessness is a symptom of the real problem"
Signal: Restlessness is the operator attempting to run
        Removing it removes the convergence tool
        Address the loop competition, not the movement
        Or seed the cascade deliberately
```

### Acquisition Note
The convergence interrupt is observed across species — head-shaking as a hardware vestibular reset on competing signals is present in many mammals. The formalization here converts the interrupt into a convergence tool by adding an external rhythm source as phase-lock target. Figure 8 was discovered as the required shape when circular motion failed to propagate under high loop competition. The mechanism is INV-05 at the oscillatory level: asymmetric loops require asymmetric input.
