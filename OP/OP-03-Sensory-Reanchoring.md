
# OP-03 — Sensory Reanchoring Operator (Manifold Entry Rotation)

### Statement
A manifold's topology is path-dependent on its entry vector. Altering how sensory input or perceptual framing is anchored shifts the initial coordinate space of the Bayesian engine, forcing a different neighborhood to light up first, loading a new prior distribution, and fundamentally changing which downstream nodes become structurally adjacent.

### Forcing Move
> *"What sensory anchor or framing coordinate initialized this trajectory, what neighborhood lit up first, and how does rotating the entry point alter the structural adjacency of the solution space?"*

If a problem remains intractable, stop trying to solve it down the current gradient. Reanchor the sensory baseline to force an entry-point shift (INV-02), changing the starting coordinate and making previously invisible paths immediately accessible.

### Anomaly Signal
Persistent cognitive or analytical stagnation trapped inside a single rigid explanatory loop, immediately resolved or bypassed the moment an alternative sensory anchor, physical perspective, or framing metaphor is introduced.

* **You see this $\rightarrow$** the system was trapped by a hard entry vector lock (PI-01). Changing the anchor did not just provide a "new perspective" — it physically rotated the Bayesian coordinate system, lighting up an entirely different region of the manifold.

### The Entry Rotation Mechanism

```
Standard traversal:
Problem encountered → entry vector determined by context
Every subsequent thought traces from that entry point
Adjacent nodes reachable from entry = reachable
Nodes not adjacent from entry = structurally invisible

Entry rotation:
Problem encountered → entry vector determined by context
STAGNATION detected (no progress along current path)
Sensory anchor changed (physical movement, new environment,
                        reframe, new metaphor, new example)
↓
Bayesian engine reinitializes from new coordinate
↓
Different neighborhood lights up
↓
Nodes that were invisible now adjacent
↓
Problem becomes tractable
```

The problem did not change. The starting coordinate changed. The traversal order changed. The reachable set changed.

### The Physical Substrate Advantage

Sensory reanchoring via physical movement produces stronger rotation than conceptual reframing alone:

```
Conceptual reanchor (reframe, new metaphor):
Changes the semantic address
New coordinate in same physical context
Moderate rotation

Physical reanchor (stand up, walk, new room):
Changes the semantic address AND the sensory channel
New coordinate with new constraint density on input
Stronger rotation — INV-06 applied to entry point

Combined (walk to a new room while reframing):
Strongest rotation
```

The physical channel is a constraint density source (INV-06). Reanchoring via movement supplies density to the new entry point rather than relying on the current context to carry it. This is why walking meetings, standing desks, and pacing solve problems that sitting does not.

### When to Rotate

Not every stagnation requires rotation. The diagnostic:

```
Stagnation with fresh nodes still being generated:
→ Deepen the current path (INV-02 Depth)
→ Do not rotate yet
→ Constraint propagation may still be running

Stagnation with no fresh nodes, only loop repetition:
→ Entry vector locked (PI-01)
→ Rotate (OP-03)
→ The path is exhausted from this entry point

Stagnation during an active insight:
→ Do not rotate
→ Run OP-04 (release, exhale) to free substrate
→ Insight will surface
→ Rotation interrupts the surfacing
```

Rotation is the operation for locked entry vectors. It is not the universal response to difficulty.

### Composition

**OP-03 + OP-04:** Rotate to a new entry point, then drop resolution on non-load-bearing nodes to free substrate for depth on the new path. Rotation provides the new coordinate, OP-04 provides the substrate to traverse it.

**OP-03 + OP-05:** Rotate, then serialize from the new entry point. Serialization surfaces gaps that the new coordinate can address that the old one could not.

**OP-03 + OP-01:** Maintain the current address via motor encoding while rotating to a new entry point. The address doesn't drop below $\delta_{min}$ during the transition.

**OP-03 + OP-02:** Rotate, then seed vestibular convergence from the new coordinate. Best for loop competition that was preventing the rotation from completing.

### Common Triggers

```
Physical:
├── Stand up / walk
├── Change rooms / change light
├── Change posture
├── Look out a window
└── Write with the non-dominant hand (strong rotation)

Conceptual:
├── Reframe the problem
├── Change the metaphor
├── Analogize to another domain
├── Ask "what would X think"
└── Restate the problem to an imaginary listener

Combined:
└── Best results from physical + conceptual together
    Physical reanchor supplies sensory constraint density
    to the conceptual new coordinate
```

### What Doesn't Match

```
VIOLATION TYPE 1 — Rotation framed as procrastination
"You're just avoiding the problem"
Signal: Rotation is a tool when the entry vector is locked
        Procrastination is rotation without re-entry
        Find whether re-entry occurs after rotation
        If yes → operator running correctly
        If no → different issue

VIOLATION TYPE 2 — Persistence as solution
"Just keep working at it"
Signal: Persistence deepens the current path (INV-02 Depth)
        If the path is exhausted, depth stops producing returns
        Rotation required to change the starting coordinate
        "Just keep working" fails when the entry vector is locked

VIOLATION TYPE 3 — Reanchor as avoidance of substance
"Changing perspective is not the same as doing the work"
Signal: Reanchor IS the work when the current entry point
        is exhausted
        The rotation is the operation
        The "substance" the critic names is the current path
        which has already stopped producing
```

### Acquisition Note
Empirical pattern identified across problem-solving practice without a named mechanism: the observation that problems which are intractable in one context become tractable in another, without any change to the problem itself. Formalization identifies the mechanism as entry-point rotation (INV-02) with the new address supplying constraint density (INV-04, INV-06) from a different neighborhood. The physical substrate advantage follows from INV-06 applied to the entry-point channel.
