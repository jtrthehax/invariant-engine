# INV-02 — Update Rule

### Statement
Every system that updates does so by depth, width, or entry point shift. No fourth option exists. Amplitude commitment is the rate limiter, not intelligence or talent.

### Forcing Move
> *"Which operation was that — depth, width, or entry point shift?"*

If a discovery cannot be classified, the analysis is not complete. If it can be classified, the "genius" framing collapses. The operation is visible. The amplitude that ran it is traceable.

### Anomaly Signal
Discovery attributed to talent, luck, or inspiration **without identifying the operation.**

* **You see this $\rightarrow$** the field is describing the output, not the mechanism. The mechanism is one of three operations. Find which one.

```
Anomaly pattern:
"Breakthrough discovery by [person/team]"
No description of which operation ran
No description of amplitude committed
No description of entry point selected
↓
The discovery looks magical
because the operation is invisible
not because it was
```

### Origin
**Domain:** Minesweeper / root cause analysis
**Observation:** "Why waste time brute forcing when constraints propagate?" Every solved cell came from depth on existing nodes, expansion into adjacent space, or zooming out to see the whole board.
**Date:** Formalized 2026-10-26

```

### The Three Operations

```
DEPTH
Reclassify what you already know
Extract more precision from existing nodes
Same information → lower δ_min → more visible

Signal: "Wait — that means..."
Example: Symptoms change with breath
         → breath is the variable (not randomness)
         → go deeper on breath mechanics

WIDTH
Expand into structurally adjacent node
Prior density in adjacent domain sufficient
New node enters the manifold

Signal: "This applies there too"
Example: Individual prediction window collapse
         → institutions have prediction windows too
         → policy oscillation is the institutional readout

ENTRY POINT SHIFT
Same manifold, different starting node
Traversal order changes
Different gaps become structurally adjacent

Signal: "Nobody asked it from this angle"
Example: AI execution gates entered from
         infrastructure/networking not AI safety
         → gate architecture immediately adjacent
         → invisible from AI safety entry point
```
