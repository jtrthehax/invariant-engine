# INV-04 — Address Equals Routing

### Statement
A word is a manifold coordinate, not a label. Renaming is repositioning. The Bayesian engine keeps running on whatever address is loaded. The operation is self-concealing because it removes the vocabulary that would let the observer notice the removal.

### Forcing Move
> *"What region did that word route to before? What region does it route to now? What went dark?"*

If terminology changed, map the old and new addresses. Find the region that lost routing. That region contains what the change was designed to obscure.

### Anomaly Signal
Terminology changes *and* the mechanism in the old term's region becomes harder to discuss.

* **You see this $\rightarrow$** a semantic rehoming operation is running. Map the addresses to find the dark region.

```
Old term → structural-visibility region
New term → individual-visibility region
↓
Structural causation unreachable | Mechanism invisible
Individual behavior visible      | Structural behavior invisible
↓
Not coincidence. Routing operation.
```

### Address Types

* **STRUCTURAL-VISIBILITY ADDRESSES:** Route to regions where long-horizon modeling is possible, cross-domain integration is active, structural causation is nameable, and asymmetries are visible (e.g., *"systemic"*, *"disparity"*, *"confirmation bias"*).
* **INDIVIDUAL-VISIBILITY ADDRESSES:** Route to regions where short-horizon description is prioritized, single-domain treatment is isolated, individual agency is assumed, and structural mechanisms are rendered invisible (e.g., *"challenges"*, *"opportunities"*, *"diverse perspectives"*).

### Precision Expansion
* **Precision 1:** Words matter (incomplete; fails to name the mechanism).
* **Precision 2:** Different words produce different associations (direction is correct, mechanism is missing).
* **Precision 3:** Word = routing address $\rightarrow$ address = region activated $\rightarrow$ region = available operations (mechanism named).
* **Precision 4:** The population vector acts as the substrate (Franch 2026); the address selects the vector, which carries a neighborhood that sets gain and interrupt capacity.
* **Precision 5 (Falsifiable Test):** Rename a concept and measure downstream routing. If changing the address produces zero routing change, the invariant breaks.

### The Self-Concealment Property
1. Moves a structural-visibility address to an individual-visibility region.
2. Removes the word that routes to the structural-visibility region.
3. The word that would let an observer detect the removal is systematically purged.
4. The observer in the individual-visibility region cannot detect the smaller manifold.
5. The observer feels their reasoning is intact — *and it is*. The engine runs, the addresses are valid, but the structural region is simply unreachable.

### What Doesn't Match
* **VIOLATION TYPE 1 — "Just semantics":** *"That's just a word choice."* (Signal: Address change = routing change = reachability change. Calling it "just semantics" is the tell that the observer is trapped in the new region and cannot see what the old region contained).
* **VIOLATION TYPE 2 — Neutral renaming:** *"We updated the terminology for clarity."* (Signal: Map old vs. new. If it shifted from structural to individual visibility, the "clarity" actively removed the mechanism).
* **VIOLATION TYPE 3 — Single-domain vocabulary:** *"That's not how we talk about it in this field."* (Signal: Domain-specific address systems trap concepts. An entry-point shift is required to find the structural-visibility address).
