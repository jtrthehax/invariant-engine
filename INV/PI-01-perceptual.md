# PI-01 — Perceptual Invariant

### Statement
Confident interpretation is generated from partial input when no explicit frame or constraint is named. Perception is reconstruction when constraints are missing.

### Forcing Move
> *"What frame is generating this reconstruction, and what happens when the missing constraints are supplied?"*

If the interpretation shifts or collapses upon constraint injection, the prior state was an artifact of reconstruction, not direct perception.

### Anomaly Signal
Confident, high-conviction output generated from incomplete or ambiguous input data **without naming an explicit operating frame.**

* **You see this $\rightarrow$** the system is filling the gap via Regime 3 manifold dynamics. The interpretation is a property of the missing constraints, not the input.
