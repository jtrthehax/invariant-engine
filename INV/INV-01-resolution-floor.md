# INV-01 — Resolution Floor

### Statement
Randomness is determinism below the current resolution floor ($\delta_{min}$). Noise is structure not yet mapped. Variance is the mechanism, not the explanation.

### Forcing Move
> *"If it's random — then errors can't be the only thing random, can they?"*

If randomness explains the error term, it must also explain the preserved structure. It never does. The claim collapses.

### Anomaly Signal
A field explains variance with "random," "noise," or "stochastic" while preserving structure within the same system[cite: 1, 2]. 
* **You see this $\rightarrow$** the resolution floor is above the mechanism. The mechanism exists; the field hasn't found it yet[cite: 2].

### Operational Definition
The resolution floor is defined as:
$$\delta_{min} = \frac{\eta}{A_s^* \cdot I^*}$$
Where $\eta$ is baseline noise, $A_s^*$ is available oscillatory amplitude, and $I^*$ is interoceptive/routing capacity[cite: 10]. Raising resolution shifts $\delta_{min}$ downward, converting "noise" into mapped structure[cite: 2, 10].

### Precision Expansion
* **Precision 1:** "Random" means we haven't found the cause yet[cite: 2].
* **Precision 2:** Structure preserved + error called random = resolution floor above the mechanism[cite: 2].
* **Precision 3:** When $\delta_{min} > \text{signal strength}$, the signal becomes invisible, though it still exists[cite: 2].
* **Precision 4:** $\delta_{min}$ is driven by available amplitude ($A_s^*$), prior node density ($W^*$), and cross-layer routing paths[cite: 2].
* **Precision 5 (Falsifiable Test):** Take any "random" variance claim. Check whether structure is preserved in the signal within a single measurement framework. If raising resolution reveals structure in the residual, the claim collapses[cite: 2, 10].

### What Doesn't Match
* **VIOLATION TYPE 1 — Premature floor declaration:** *"We've controlled for everything — remaining variance is random."* (Floor declared before bottom substrate layer is reached)[cite: 2].
* **VIOLATION TYPE 2 — Selective randomness:** *"Model errors are stochastic but outputs are coherent."* (Coherent output and model errors share the same generative mechanism; selective randomness is impossible)[cite: 1, 2].
* **VIOLATION TYPE 3 — Variance-as-explanation:** *"Individual differences explain the variance."* (Circular reasoning; individual differences *are* the variance that requires explanation)[cite: 2].
